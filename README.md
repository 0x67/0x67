## Hi, I'm Gabriel

I build trading systems, market data pipelines, and on-chain infrastructure, mostly in Rust, Go, and TypeScript.

Right now I work on TER, a gold-backed real-world asset (RWA) token on Solana, and help local teams with other crypto projects.

**Trading & market data**
- Rewrote an exchange market data feed handler from C++ to Rust: 300k+ messages/sec on ~15x less memory
- Led a team building a desktop trading app in Tauri, with a Rust core and React client
- Cut an end-of-day pipeline processing 2M+ records from 40+ minutes to under 5

**On-chain**
- Built a DEX execution engine that routes orders across Ethereum, Base, BSC, and Solana
- Built custodial deposit and withdrawal pipelines for EVM chains and Solana
- Built DeFi data ingestion across several chains, served from a 100M+ row database at millisecond latency
